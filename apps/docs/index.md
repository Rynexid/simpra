# Simpra Docs

Welcome to the Simpra documentation. This guide covers platform setup, architecture, feature usage, and API reference.

## What is Simpra

Simpra is a modern inventory and warehouse platform for managing stock, warehouses, suppliers, purchasing, and analytics in one place.
